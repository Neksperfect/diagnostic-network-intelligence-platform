# DNIP Data Dictionary

## 1. Purpose

This document describes the columns exposed by the PostgreSQL `core`
schema, including the two financial reporting views returned by the
schema inspection.

Column names, data types, nullability, defaults, and identity indicators
are transcribed from the supplied PostgreSQL
`information_schema.columns` output.

**Scope:** 30 base tables and 2 views. The views are documented
separately because they are derived reporting objects, not transactional
tables.

**Description note:** Table purposes are concise functional descriptions
based on the project model. Column names and database metadata are
exact; detailed business definitions can be refined as the
data-generation and reporting logic is implemented.

## 2. Metadata conventions

  Attribute   Meaning
  ----------- ---------------------------------------------------------
  Data type   PostgreSQL type, including declared length or precision
  Nullable    `YES` permits NULL; `NO` means NOT NULL
  Default     Database default expression, if defined
  Identity    `YES` indicates a PostgreSQL identity column
